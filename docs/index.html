Jupyter Notebooks Workflow Pipeline

Notebook 1: Backfill Feature Group (`notebooks/1_backfill_feature_group.ipynb`)

Fetches historical IoT air quality measurements & backfills Hopsworks Feature Group `air_quality_hourly_fg`.

Notebook 2: Daily Feature Pipeline (`notebooks/2_daily_feature_pipeline.ipynb`)

Daily GitHub Actions cron retrieving fresh hourly measurements and updating Feature Store.

Notebook 3: XGBoost Training Pipeline (`notebooks/3_training_pipeline.ipynb`)

Trains XGBoost Regressor model on time-series feature view and logs artifact to Hopsworks Model Registry.

Notebook 4: Batch Inference & Hindcast Graphs (`notebooks/4_batch_inference_pipeline.ipynb`)

Downloads registered model from Hopsworks, predicts 72h future AQI, generates hindcast evaluation graph, and updates GitHub Pages site.

Notebook 5: LLM Personalized Advisory (`notebooks/5_llm_personalized_recommendations.ipynb`)

LLM chain generating personalized health advice for athletes, children with asthma, and senior citizens.
